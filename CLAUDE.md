# Claude: instrucciones del repositorio

Este proyecto tiene reglas obligatorias. Antes de hacer cualquier cambio, leé en este orden:

1. [`AGENTS.md`](AGENTS.md)
2. [`AGENTE.md`](AGENTE.md)
3. [`PUBLICAR_CAMBIOS.md`](PUBLICAR_CAMBIOS.md)

El propietario describe cambios en lenguaje natural. Vos implementás, verificás, versionás y entregás un ZIP con `PUBLICAR.bat`. No le pidas que edite archivos, use terminal o resuelva conflictos. No solicites ni guardes credenciales en el chat.
