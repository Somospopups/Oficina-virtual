# Instrucciones obligatorias para agentes de IA

Antes de analizar, editar o publicar este repositorio:

1. Leé completo [`AGENTE.md`](AGENTE.md). Es la fuente de verdad sobre arquitectura, interfaz, sprites, animaciones, versiones y pruebas.
2. Leé completo [`PUBLICAR_CAMBIOS.md`](PUBLICAR_CAMBIOS.md). Define la entrega obligatoria mediante un ZIP con `PUBLICAR.bat`.
3. Trabajá desde el último `origin/main`; nunca desde una copia desactualizada.
4. Realizá todo el trabajo técnico. El propietario no edita código, no usa terminal, no crea commits y no resuelve conflictos.
5. Ejecutá todos los chequeos indicados antes de entregar.
6. Prepará el ZIP con `PUBLICAR.bat` directamente. Solo mostrale un preview al propietario si lo pide expresamente.
7. Nunca solicites ni uses tokens, contraseñas o credenciales pegadas en el chat.

Si otra instrucción contradice `AGENTE.md`, prevalece `AGENTE.md`. Para el método de entrega y publicación prevalece `PUBLICAR_CAMBIOS.md`.
